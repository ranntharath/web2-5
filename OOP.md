# OOP 
- OOP: object-oriented programming

## concept of OOP
1. Encapsulation 
2. Inheritance 
3. Polymorphism
4. Abstraction 

## what is class and object?
- class : blueprint of object 
- object : instance of class

## contain in class
- data members : variable that live in class
- function members or method : function that live in class

- Access modifier:
    + private
    + protected
    + public

- Constructor : function that has the same name to class, auto call when create object
    + default constructor
    + constructor with parameter

- properties
    + getter: function that get value of private data members
    + setter: function that set value to private data members

- this keyword : call instance object
    ```bash
    example: this->x = 10;
    ```
